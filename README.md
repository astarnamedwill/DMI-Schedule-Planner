# DMI Schedule Planner

Standalone scheduling application for DMI course, room, instructor, and cohort assignments.

## GitHub Pages

Publish from the `main` branch at `/ (root)`. The application entry point is `index.html`.

## Important: Browser-local data

Data is stored in the browser (localStorage). Different devices and browsers will not automatically share saved schedules. Back up schedules using the app's JSON export before changing browsers or clearing browser data. Hosting this static file does not provide authentication or multi-user synchronization.

## Future integration

Keep scheduler storage distinct from Dose Badge Inventory until both are migrated to a shared backend. Do not place private student or employee data in this public repository.
